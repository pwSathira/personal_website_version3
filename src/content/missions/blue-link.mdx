A mobile data terminal is the computer in a patrol car: officers sign in, look people up, and file charges from the road. Blue-Link is my version, which I wrote alone between June 2023 and January 2024.

## I drew the screens before writing Swing

I mocked up the login and report screens in Illustrator first, then built the components the mockups needed: rounded panels and text fields, and icons recoloured at runtime to match the theme. FlatLaf handles the base look; MigLayout handles the grids.

## The client connects straight to the database

Each terminal opens its own JDBC connection to Azure SQL, so each terminal holds database credentials: acceptable for a student project, wrong for a police force. Its successor puts an API and a sign-in service between the two.

<CredsDiagram caption="Where the database password lives, in Blue-Link and in NyxOps." />

## NyxOps is Blue-Link's successor

[NyxOps](https://github.com/NyxOps) is an open-source records management system for police that I run as its own organization. It starts from what Blue-Link got wrong: a web client instead of a desktop install, sign-in and permissions handled by Keycloak instead of the client, and the database reachable only through the API. It's in early development.
